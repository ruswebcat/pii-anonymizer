# Правила склонения русских имён, фамилий и отчеств

Источник: petrovich/petrovich-rules (https://github.com/petrovich/petrovich-rules)
Лицензия: MIT — файл LICENSE лежит рядом, атрибуция обязательна при распространении.

Файлы `suffixes.json` и `exceptions.json` взяты из репозитория без изменений.
Используются как таблицы правил: окончание → падежные формы и список несклоняемых.
Код, который их читает, — наш (`src/name_forms.py`), поэтому производных данных
из этих таблиц не создаётся: они поставляются как есть, с лицензией и атрибуцией.
