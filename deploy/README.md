# Развёртывание прокси обезличивания

Всё разворачивается на том же хосте контура, что и агент.
Прокси слушает **только** `127.0.0.1:8791`, провайдерские ключи живут в нём, а не
в профиле агента.

## Порядок

1. **Словарь (первое наполнение).** Пока прокси не запущен, выгрузить словарь
   известных ПД из CRM — иначе первые дни он работает на одних правилах:

   ```bash
   python3 src/dict_export.py --preview --max-pages 3   # проверка схемы
   python3 src/dict_export.py --out /var/lib/pii-proxy/pii_dict.json
   ```

2. **Установка юнита:**

   ```bash
   bash deploy/install.sh          # каталоги, ключи, env-файл, unit, без запуска
   sudo nano /etc/pii-proxy/pii-proxy.env   # вписать ключи провайдеров
   bash deploy/install.sh --start  # поднять и проверить healthz
   ```

3. **Проверка перед переключением:**

   ```bash
   curl -s http://127.0.0.1:8791/healthz | python3 -m json.tool
   ```

   В ответе должны быть: `store`, `cache`, `dictionary.counts`, `ner.available`,
   `rarity`. Если `ner.available=false` — не установлен `pymorphy3`
   (`python3 -m pip install pymorphy3 pymorphy3-dicts-ru`, ~17 МБ).

4. **Переключение агента** (отдельный шаг, только после явного решения владельца):
   в профиле агента `model.base_url` → `http://127.0.0.1:8791/ds/v1`, ключ
   провайдера заменяется заглушкой. Проверка — `hermes doctor` и одна реальная
   сессия; откат — вернуть прежний `base_url` и ключ.

5. **Крон выгрузки словаря** — раз в неделю, без LLM (0 токенов):

   ```
   0 3 * * 1  /opt/pii-proxy/deploy/dict-export.sh
   ```

## Что нужно помнить

- **Ключи и справочник несменяемы на ходу.** Удаление `token.key` или
  `pii_map.db` при работающем прокси делает старые токены неразрешимыми, а
  запись в справочник невозможной — прокси ответит `403` (fail-closed). Именно
  так и должно быть, но лучше не проверять это на бою.
- **Детокенизация только на доверенных каналах и в локальных файлах.** Канал вне контура получает
  токены: канал считается внешним.
- **Картинки** при `PII_PROXY_BLOCK_IMAGES=true` отклоняются: их нельзя
  обезличить.
- **Журнал** `/var/log/pii-proxy/audit.jsonl` пишется по закрытой схеме —
  значений в нём нет по построению.
- **Откат:** `sudo systemctl stop pii-proxy` + вернуть `model.base_url`
  агента. Прокси не хранит состояние, кроме справочника и журнала.
